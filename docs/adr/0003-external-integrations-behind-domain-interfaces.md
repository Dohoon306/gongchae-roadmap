# 외부 연동은 domain의 인터페이스 뒤에 두고, 구현체는 같은 도메인의 infra에 둔다

상태: accepted (2026-11-26)

잡알리오 공고 조회와 AI 호출 같은 외부 연동은 인터페이스를 해당 도메인의 `domain` 패키지에, 구현체를 같은 도메인의 `infra` 패키지에 둔다. 외부 응답 형식(잡알리오 JSON, OpenAI 응답)은 구현체 안에서 도메인 객체로 변환하고, 구현체 밖으로 내보내지 않는다.

잡알리오 키가 발급되기 전에는 샘플 데이터로 개발하고(`docs/research/job-data-sources.md`), AI는 OpenAI로 시작하되 바꿀 수 있어야 한다(`docs/01-idea.md`). 그래서 샘플 데이터 구현체와 실제 API 구현체를 설정만으로 교체할 수 있어야 하고, 외부 형식이 서비스나 화면까지 새어 나가면 교체할 때 여러 계층을 고쳐야 한다.

## Consequences

- 잡알리오 응답 필드명은 아직 확인되지 않았다. 필드명이 정해져도 바뀌는 곳은 `infra`의 실제 API 구현체 하나다.
- 테스트에서는 샘플 구현체나 가짜 구현체를 끼워 외부 호출 없이 흐름을 검증한다.
